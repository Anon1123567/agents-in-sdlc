Explore o GitHub Copilot nas várias etapas do ciclo de vida do desenvolvimento de software por meio de situações realistas, um aplicativo completo e um backlog compartilhado. Você vai trabalhar de forma iterativa para planejar alterações, criar código, testar o comportamento, revisar pull requests e gerenciar o trabalho com agentes.

## Cenário

Você é um novo desenvolvedor na Tailspin Toys, uma empresa fictícia que financia coletivamente jogos de tabuleiro com temas de desenvolvimento. O backlog da equipe já está registrado como issues do GitHub, e você pode começar a trabalhar nelas. Ele inclui tarefas de funcionalidades, como filtros e paginação, e melhorias de qualidade, como acessibilidade e padrões de código.

## Escolha seu ambiente

O GitHub Copilot está disponível onde você trabalha. Escolha o ambiente que melhor combina com seu fluxo de desenvolvimento. Cada workshop começa com sua própria configuração e usa o cenário compartilhado da Tailspin Toys.

### [GitHub Copilot CLI][cli]

Use o assistente agêntico no terminal. Trabalhe com os modos Plan e Autopilot, instruções, skills, agentes personalizados, Playwright MCP, Agent Merge e comandos slash úteis.

### [Aplicativo GitHub Copilot][app]

Execute sessões de agentes em paralelo, alterne os modos de sessão, colabore no canvas e gerencie issues e pull requests do GitHub no aplicativo para desktop.

### [GitHub Copilot cloud agent][cloud]

Atribua issues do GitHub a um agente assíncrono, oriente o trabalho, acompanhe o progresso e revise os pull requests que ele abrir.

### [Visual Studio Code][vscode]

Use o GitHub Copilot no Visual Studio Code e no GitHub Codespaces. Trabalhe com o modo de agente do Copilot Chat, servidores MCP e agentes personalizados sem sair do editor.
