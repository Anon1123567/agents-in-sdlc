優れた CLI ツールと同様に、GitHub Copilot CLI には対話に使えるスラッシュコマンドが多数用意されています。コマンドを使うと、高度な機能、内部情報、追加の構成オプションを利用できます。これまでに `/diff`、`/mcp`、`/skills`、`/agent`、`/pr` などを使いました。ここでは、ほかの便利なコマンドを確認します。

このレッスンでは、次のことを行います。

- `/context` と `/compact` を使い、Copilot が会話のコンテキストを管理する方法を確認します。
- `/model` を使い、利用可能なモデルを確認します。
- `/share` でセッションをエクスポートまたは共有する方法を学びます。
- 並行作業、worktree、クラウドエージェントへの委任に関する任意のコマンドを確認します。

## シナリオ

CLI の主なワークフローが完了しました。次は、コンテキストの管理、モデルの切り替え、セッションの共有、そして任意で [Copilot クラウドエージェント][about-cloud-agent]に作業を委任するなど、追加機能を確認します。

## Copilot CLI のコンテキストを確認する

大規模または複雑なタスクに取り組むと、モデルが処理できるコンテキストウィンドウの上限に達する場合があります。Copilot CLI は必要に応じて会話を自動的に圧縮します。スラッシュコマンドを使って、状態を確認したり、自分で圧縮したりすることもできます。

1. Codespace に戻り、Copilot CLI が起動していない場合はリポジトリのルートから起動します。
2. 次のコマンドを入力します。

   ```plaintext
   /context
   ```

3. モデル、現在のトークン使用量、システム手順、ツール、メッセージ、空き容量にコンテキストがどのように配分されているかを確認します。
4. 会話を圧縮します。

   ```plaintext
   /compact
   ```

5. もう一度 `/context` を入力して結果を比較します。会話が短い場合は、あまり変化がないこともあります。

> [!NOTE]
> コンテキストウィンドウが埋まると、Copilot CLI が自動的に圧縮します。タイミングを自分で選びたい場合は `/compact` を使います。関係のない別のタスクに切り替えるときに新しい会話を始めるには、`/clear` または `/new` を使います。

## モデルを選ぶ

モデルごとに得意分野が異なり、開発者によって好みも異なります。Copilot CLI では、利用可能なモデルを一覧表示し、使用するモデルを選択できます。

1. 次のコマンドを入力します。

   ```plaintext
   /model
   ```

2. 利用可能なモデルと使用状況の情報を確認します。
3. 現在のモデルを使うか、別のモデルを選ぶか、<kbd>Esc</kbd> を押して一覧を閉じます。

## セッションを共有する

チームで協力し、学んだことを共有すると、AI ツールの活用方法を互いに改善できます。`/share` コマンドを使うと、セッションを Markdown または HTML ファイルにエクスポートしたり、共有可能なリンクを作成したり、GitHub gist を公開したりできます。

1. `/help` を入力し、インストール済みのバージョンにおける `/share` のオプションを確認します。
2. セッションを共有する場合は、用途に合った出力先を選びます。たとえば `/share file` では、ローカルに Markdown をエクスポートできます。
3. エクスポートした内容を誰かに送信したり公開したりする前に確認します。セッションのエクスポートには、プロンプト、応答、プロジェクトの詳細が含まれる場合があります。

リンクや gist の公開は任意です。チームが共有するつもりのないリポジトリや会話の内容を公開しないでください。

## 任意: 作業を拡張または委任する

ワークショップの主要な内容は完了しました。大きなタスクには、Copilot CLI の次のコマンドも利用できます。

- `/fleet` は、独立したサブタスクをサブエージェントに分割し、並行して実行できます。
- `/worktree` は、別のタスク用に独立した Git worktree を作成できます。
- `/delegate` は、非同期で作業し、プルリクエストを開くこともできる Copilot クラウドエージェントにタスクを送信できます。

追加の worktree やリモート作業が発生するため、これらのコマンドは任意です。試すときは、範囲の明確な新しいタスクから始め、通常のワークフローに沿って結果をレビューしてください。非同期エージェントの作業について詳しく知りたい場合は、[クラウドエージェントのワークショップ][cloud-workshop]に進んでください。
