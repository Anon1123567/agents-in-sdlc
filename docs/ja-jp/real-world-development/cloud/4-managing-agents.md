前のいくつかの演習では、Copilot クラウドエージェントにユーザー体験の改善と機能追加を目的とする 3 つのタスクを依頼しました。クラウドエージェントは非同期かつ自律的に作業しますが、タスクを監視することも重要です。

クラウドエージェントに割り当てたタスクを管理する方法はいくつかあります。[GitHub.com のエージェントページ][agents-page]もその 1 つです。このミッションコントロールでは、オープンなプルリクエスト (PR) があるすべてのエージェントタスクを確認できます。実行内容を調べたり、進行中のセッションに指示を追加したりできます。

このレッスンでは、次のことを行います。

- エージェントページを開き、クラウドエージェントのタスクを監視します。
- 進行中のセッションに指示を追加し、機能を拡張します。

## シナリオ

エージェントに高コントラストモードの作成を依頼した後、チームはライトモードも追加するよい機会だと考えました。サイトのスタイルを更新し、切り替え機能も追加する作業をすでに進めているため、ライトモードも含めるのが合理的です。エージェントの作業に指示を追加し、高コントラストとライトモードの両方を実装させます。

## Copilot クラウドエージェントのタスクを確認する

Copilot クラウドエージェントに割り当てたタスクの現在の状況を確認します。

1. [Copilot エージェントのページ](https://github.com/copilot/agents)に移動します。
2. メインペインと左ペインの両方でタスク一覧を確認します。次のような、Copilot に割り当てたタスクが表示されます。
   - コードベースのドキュメントを更新する。
   - ゲーム変更用の API を生成する。
   - Web サイトに高コントラストモードを追加する。
3. 実行中のタスクを選択し、Copilot が実施した作業を確認します。次のような内容があります。
   - リポジトリをチェックアウトする。
   - Copilot の環境を作成する。
   - MCP サーバーを設定する。
   - 割り当てられたタスクを完了するための作業を行う。

> [!NOTE]
> 表示される手順は、Copilot の作業状況や進め方によって異なります。

4. 右側に表示されるプルリクエスト (PR) のペインを確認します。PR や変更されたファイルを確認して、さらに詳しく監視できます。

## クラウドエージェントに指示を追加する

アクティブなタスクを確認したので、高コントラストモードの作業中にライトモードも追加するよう Copilot に依頼します。

1. 高コントラストモードを追加するセッションを選択します。エージェントが付けた名前や作業状況によって、セッションのタイトルは異なります。

    ![ミッションコントロールのアクセシビリティセッション](../../../_images/ex6-accessibility-session.png)

2. セットアップが完了し、作業を開始したことが表示されるまで、数分間セッションを確認します。作業開始後は、次のようなメッセージが表示されます。
3. **Steer active session while Copilot is working** ダイアログに次のプロンプトを入力します。

    ```plaintext
    While we are working on a high contrast mode, let's also add a light mode. There should be a switch for this mode as well where users can select their desired display mode.
    ```

    ![エージェントページで、Copilot の作業中にアクティブなセッションへ指示を追加するダイアログを示すスクリーンショット](../../../_images/ex6-steer-cloud-agent-task.png)

4. <kbd>Enter</kbd> を押してプロンプトを送信します。
5. Copilot がプロンプトを受け取り、作業に取り込んだことを確認します。

## Copilot に作業を続けさせる

これまでと同様に、Copilot は更新されたタスクに取り組みます。メッセージを送信した時点で作業中の手順が終わると、新しい要求を作業の流れに取り込みます。

今回も数分かかります。これまでに学んだことを振り返りながら待ちましょう。

## まとめと次のステップ

このレッスンでは、Copilot エージェントのページを確認しました。ここは、Copilot クラウドエージェントのタスクを監視し、指示するための中心的な場所です。ミッションコントロールで、アクティブなタスクと完了したタスクを追跡し、実行中の作業を確認し、進行中のタスクに指示を追加できます。

ここでは、次のことを行いました。

- ミッションコントロールとエージェントページで、クラウドエージェントのタスクを監視しました。
- 進行中のセッションに指示を追加し、機能を拡張しました。

Copilot がアクセシビリティ機能に取り組んでいる間に、次は Copilot が作成したプルリクエストを[反復改善][next-lesson]します。
